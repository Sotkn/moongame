# Moon Courier Crisis

Симулятор лунной доставки: база, роверы, заказы на карте. Цель — заработать максимум денег за 3 дня.

## Запуск

Нужен Python 3.12+.

```bash
python -m venv .venv
source .venv/Scripts/activate   # Windows cmd: .venv\Scripts\activate
pip install -e .
python -m moon_game
```

## Что сделано

- Карта Луны, точки заказов, роверы едут по маршруту.
- Заказы: вес, награда, срок, риск маршрута.
- Роверы: батарея, грузоподъёмность, статус.
- Выбор ровера, заказа и маршрута → Send. На Ridge два пути: короткий (высокий риск) и длинный (низкий).
- Магазин: можно купить ровер за деньги (Мул тянет тяжёлые заказы, Спринтер быстрее).
- SQLite: стартовые роверы и заказы, журнал доставок и событий.

## Структура

Слои разделены: UI не считает доставку, симуляция не рисует, правила не зависят от pygame.

| Модуль | За что отвечает |
| --- | --- |
| `App`, `Session` | Запуск и кадр: команды игрока, тик, запись в SQLite |
| `GameState` | Состояние сессии (роверы, заказы, деньги, фаза дня) |
| `Simulation` | Время, движение, батарея, риск на маршруте |
| `commands` | Действия игрока (`StartDelivery`, `BuyRover`, …) → `apply` на state |
| `assignment`, `purchase`, `hazard` | Правила: можно ли отправить / купить, расход энергии, сбой |
| `entities` | Типы: `Rover`, `Order`, `Route`, `Delivery` |
| `Ui` | Клики → команды, отрисовка. Не двигает роверы |
| `world/`, `storage` | Сценарий (карта, маршруты, магазин) и SQLite |

## Логика

**Вес.** Если заказ тяжелее вместимости — Send недоступен. Тяжёлый груз сильнее сажает батарею. «Руда» (вес 20) не влезает ни в один стартовый ровер (макс. 10) — без покупки Мула доставка невозможна.

**Батарея.** Расход на туда-обратно растёт с длиной маршрута и весом. Не хватает заряда — отказ.

**Риск.** У маршрута свой риск. На коротком Ridge он высокий: в середине пути возможен сбой (пауза и доп. расход батареи). Длинный Ridge безопаснее, но дольше — можно не успеть к сроку.

**После доставки.** Деньги += награда, заказ выполнен, ровер дома с оставшейся батареей. Просроченный заказ — провал. К ночи активные рейсы обрываются без оплаты.

## Данные

SQLite: `data/moon.sqlite` (создаётся при первом запуске).

| Таблица | Что |
| --- | --- |
| `rovers`, `orders` | Стартовый парк и заказы дня |
| `deliveries`, `events` | Журнал рейсов и событий |

Карта, точки, маршруты и магазин заданы в коде (`world/`). Симуляция идёт в памяти; в базу пишется только журнал.
